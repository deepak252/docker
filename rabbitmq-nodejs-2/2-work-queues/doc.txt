> await channel.assertQueue(queue, { durable: true });
    durable: true (Queue Persistance)→ if RabbitMQ restarts, this queue will not be lost.

> channel.sendToQueue(queue, Buffer.from(message), {persistent: true});
    persistent: true (Message Persistance) → Messages are written to disk.

> channel.consume( queue, (message) => { channel.ack(message); }, { noAck: false } );
    noAck: true (Automatic acknowledgment) → RabbitMQ removes the message immediately after sending it to the consumer (even if the consumer crashes).
    noAck: false (Manual acknowledgment) → RabbitMQ waits for an explicit channel.ack(msg); before removing the message. If the consumer crashes before ack, the message re-delivers to another consumer.
    channel.ack(msg) → tells RabbitMQ that the message was processed successfully, so it can be deleted from the queue.

>  channel.prefetch(1)  // Allow only 1 unacknowledged message at a time
    The channel.prefetch(count) method limits the number of unacknowledged messages a consumer can receive at a time. It helps in load balancing and preventing message overload on a single consumer.
    Multiple consumers processing a queue
    Best Practice: Use prefetch(1) for long-running tasks to avoid memory issues.
