Reset table, eg.:
    > delete from panelists;
    > alter table panelists auto_increment = 1;

DB Disk Usage:
    > sudo du -sh /var/lib/docker/volumes/mysql_mysql_ingest_data/_data

DB Files:
    > du -sh /var/lib/mysql/*

Database Table Sizes
    > SELECT  table_schema AS database_name,     table_name,     ROUND((data_length + index_length) / 1024 / 1024, 2) AS size_mb FROM information_schema.tables where table_schema = 'productsdb';

Run:
1. docker compose up
2. Producer:
    > cd producer
    > uvicorn app.main:app --host 0.0.0.0 --port 8084
    > uvicorn app.main:app --host 0.0.0.0 --port 8084 --workers 4
3. Consumer:
    > cd consumer
    > python -m app.main

Reset table, eg.:
    > delete from panelists;
    > alter table panelists auto_increment = 1;

DB Disk Usage:
    > docker inspect <mysql container id>
    > sudo du -sh /var/lib/docker/volumes/mysql_mysql_ingest_data/_data
